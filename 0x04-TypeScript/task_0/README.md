# Task 0 - Creating an Interface for a Student

## 📚 Learning Objectives

At the end of this task, you should be able to:
- Explain and define basic types in TypeScript
- Create and use an interface
- Manipulate the DOM using TypeScript
- Configure Webpack and TypeScript to compile without errors

---

## 🧩 Task Description

Write a TypeScript script that:
1. Defines an interface `Student` with the following properties:
   - `firstName` (string)
   - `lastName` (string)
   - `age` (number)
   - `location` (string)
2. Creates two student objects.
3. Stores them in an array called `studentsList`.
4. Uses **Vanilla JavaScript (DOM manipulation)** to render a table that displays the `firstName` and `location` of each student.
